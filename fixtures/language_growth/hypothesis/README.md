# Illustrative conditional reasoning

These two authored development fixtures exercise an opt-in registered assumption
through the existing semantic checker and deterministic renderer. They do not
alter the frozen fixture pack or contain held-out data. Both embed their complete
synthetic checking authority and original factual catalog.

`registered_assumption.json`: Atlas's factual price remains 199.90 USD; under the
host's registered 99.90 USD assumption, it would be below Boreal's 149.90 USD.
Only an explicitly conditional speech act is released.

`inline_model_fact.json`: an extra model-supplied value in the assumption operand
refuses with `unsupported_field`.

Run `py -3 -m unittest language_growth.tests.test_hypothesis`. This demonstrates
the bounded semantic operation, not learned L2 performance or gate passage.
