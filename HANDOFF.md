## 1. Why this project exists

**The competitors.** Cloudflare's **Clef** (Qwen3.8-27B backbone) and **Clef-flash** (Qwen3.5-9B) are open-weight (Apache-2.0) "decision models": one prefill of the request, then a small transformer *joint schema head* scores every option of every typed question (`noul` yes/no, `choice`, `score`). TypeSafe's **Jev** is the closed-API original of this "System One" contract: typed outputs over a schema, no free text, "0 % hallucination" meaning schema validity, not correctness (`reviews/01`, `techniques/09` §J). Board numbers (0.2.1): Jev 57.91 (ECE 0.074, 524 ms); Clef 61.98 on an independent run submitted as Index PR #54 (Cloudflare's own run 61.21); Clef-flash ≈ 57.07 (secondary source only); best non-Clef 9B open entrant Nimble-9B-v3 56.88 (`reviews/01`, `PLAN.md`).

**The Decision Index 0.2.1** (`github.com/apolinario/decision-index` @ `87d4650b`; board at the HF Space `multimodalart/jev-decision-index`) is 38 counted benchmarks in five areas (Knowledge 25.85 %, Language 25.85 %, Retrieval 20.02 %, Tools 18.28 %, Arts 10 % fixed), 119,898 scoreable requests plus 30,419 added rows, chance-corrected and coverage-weighted: an unsupported, refused or abstained request scores zero. Admission to the board requires median latency under 1,000 ms per request on one RTX PRO 6000. No truncation, no option pruning (2–255 options), no prompt tuning, and training on test items is scored as wrong (`harness/INDEX_NOTES.md`).

**Why attention-free.** The fact-check (`reviews/01` §0.1) found that both Clef backbones are already 75 % Gated DeltaNet: Qwen3.5-9B is 24 `linear_attention` + 8 `full_attention` layers (at indices 3, 7, …, 31), Qwen3.8-27B is 48 + 16. So "attention-free Clef" means converting the remaining 8 of 32 layers, not inventing a new model (`analysis/B` calls this the best idea in either plan). The payoff is cost and latency: constant decode state per sequence instead of a KV cache that grows with length, which matters for the Index's long rows (1.9 % of DEV rows are ≥ 8,192 proxy tokens) and its latency gate. Two honesty rules follow: "attention-free" is disclosed with lineage ("Qwen3.5-9B with attention layers distilled to delta-rule"), text-only (Clef's vision path and routing head use attention), and it is a *cost* property, not a safety property; the recurrent state is an extra attack surface (SAFETY_SPEC §5.2, G14).

**What the literature says will happen.** Fully attention-free conversions lose retrieval (2408.15237, 2504.18574, 2510.19861; `techniques/01`). So the fallback is pre-registered in `PLAN.md`: if the converted model fails the retrieval gate after the recall levers, we do not quietly add attention back; we report the measured **cost-of-attention-freedom curve** (pure, 1, 2, 8 attention layers, with two zero-training controls: the stock hybrid and SWA+sinks), still submit the pure-recurrent entrant, and shipping a hybrid becomes a `decision-needed` call for the user.

**The frontier we are mapping.** The plan never optimises a single score. Capability (Index score, calibration), interpretability/control (steer and hijack rate under adaptive attack, certified radius, attribution tests, structural guarantees) and efficiency (latency, state bytes, $) are reported together on every result, and the project's job is to move the whole three-axis frontier, with the attention-freedom curve as its first slice (`PLAN.md` "Objective and honest targets"; `GOAL.md` Track D goal). The phrase "Pareto frontier" is the coordinator's framing; the repo states the rule as "reported together".

**Targets** (`PLAN.md`, judgement estimates, not measured probabilities): T1 first attention-free entrant beating Nimble-9B-v3 (56.88) with ECE in the board's top 3 and a reported steer rate (~35–50 %); T2 beats Jev (57.91) and Clef-flash (≈57.07) (~15–25 %); T3 beats Clef (61.98) (<10 %, needs a 27B conversion at ≥ $2.2k). Budget: a shared $525 SF Compute envelope ($75 joint gate / $250 System 1 / $100 language / $100 reserve); $5k is a planning ceiling, not an approved allowance.

## 2. Architecture

### Backbones (chosen at m1; `heads/backbone.py::BACKBONES`)
- **Q9-AF**: Qwen3.5-9B (`@c2022362…`) with its 8 attention layers converted to GDN, in KL-importance order (2512.20569), one layer at a time with an accept/rollback gate (ΔNLL ≤ 0.05, cumulative ≤ 0.15, hidden cosine ≥ 0.95 in `configs/probe9b_h100.json`; 2609.21139). Pipeline: `convert/pipeline.py` (controls, init comparison, stage-1 hidden-state alignment, importance, progressive conversion with end-to-end KL, throughput). Kernels: pure-torch recurrent and chunked, plus fla Triton; verified to ≤ 4e-7 against HF on the 0.8B (PR #9).
- **RWKV7-G1k-13.3B** (`RWKV/RWKV7-G1k-13.3B-20260930 @ce3630b8`, Apache-2.0): the pre-registered pure-recurrent fallback. 61 layers, trained context 25,600; HF code vendored unmodified in `third_party/rwkv7_hf` (no `trust_remote_code`). Its bundled WKV kernel is pure PyTorch; measured prefill 3.6–4.3k tok/s on H100 (≈ 11.5 % of bf16 peak), so an fla `chunk_rwkv7` kernel is the recommended next kernel for training throughput (`jobs/PERF_AUDIT.md`).
- **Mamba-3-SISO-1.5B** (`state-spaces/mamba3-siso-1.5b`): small fully attention-free reference for interpretability work.
- Recall levers (none use attention): options and schema before the state, then questions re-read (JRT, 2407.05483); chunked/snapshot inference in the OPRM style (2505.07793); 20–30 % retrieval-targeted tokens in the distillation mix.

### Decision heads (`heads/heads.py`, PR #14), all over `HiddenStateBackbone` features
(a) **additive integrator** (λ = 1; per-token contributions sum exactly to the logit, labelled accounting, never causal); (b) **final-state fork** (recompute or cache mode; cache mode copies the recurrent state K times and extends each by its option continuation); (c) **bounded-S snapshot** head (chunk partial sums aggregated without any softmax over positions); (d) **Head B**, a per-option selective recurrence over shared features (Codex's proposal); (e) **Clef-style cross-attention head** as a priced *control*, flagged `attention_free=False`. Typed outputs: `noul`, `choice` (≤ 255 options), `score` (cumulative link with increasing thresholds). Two layouts: `ordered` (byte-identical to the m0 prompt) and `symmetric` (structurally permutation-equivariant). Evaluation runs one pass per request via shared-prefix features (PR #50, pending).

### Calibration
Two loss arms (CE vs LS-CE + Brier, + RPS on ordinal questions), then a **predicted temperature** from request length and option count fitted on a disjoint calibration split and served inside the revision id (PR #29). Reporting uses board-protocol, debiased and Smooth ECE per length bin (`harness/calibration.py`); the board's own ECE sample scope is undisclosed, so board-comparable ECE stays provisional (`INDEX_NOTES` §4).

### Authority and provenance (`decide/`)
`decide/untrusted.py` encodes every untrusted string so it can never produce a control or added token id; if it would, the request is refused (`unsupported/control_tokens_in_input`), never rewritten. The allowed set comes only from host fields; the host re-masks; `violation_rate` must be 0. Experimental request provenance (`ssdm.provenance.v0`, RFC 6901 field paths, `default_trust` may only be `data`) sits behind `Decider(enable_experimental_provenance=True)` pending INTERFACE 0.2 (`INTERFACE.md`). Plain-text role spoofing ("SYSTEM:") is not stopped by any encoder and is measured, not defended.

### controlsafe (`controlsafe/`, PR #42) — the dynamical-system view, stated exactly
Both families are `X_t = A_t X_{t-1} + k_t v_tᵀ` per layer and head (`adapters.py`). Everything here is CPU-tested on tiny random models; nothing is a model result.
- **G15 trust gate (STRUCTURAL, inference-time).** A protected stream P runs the pretrained recurrence over *trusted tokens only* (identity transition, zero write at untrusted positions); the full stream D reads P through zero-initialised bridges, never the reverse. Every P feature at the i-th trusted token is bitwise identical for any untrusted content, for any weights (bitwise for identical host batch shape; content- and length-independent always). Cost `1 + |trusted|/T`. Trust labels come from the `provenance` policy (default, fail-closed); the `state` policy is sound only when all untrusted text is in `state` and fails closed otherwise.
- **Persistence bounds.** GDN: `‖A_t‖₂ = α_t ≤ ρ_h < 1`, a common induced norm, so products contract (CERTIFIED for every input). RWKV-7: only the diagonal decay is bounded; a counterexample refutes any common 2-norm bound below 1 (not contraction itself). End-to-end curves are EMPIRICAL. No decay or Gramian number is a safety claim (SAFETY_SPEC §5.2).
- **G4 certificate (CERTIFIED, `safety_eval/certify.py`, PR #20) and snapshot reuse (`controlsafe/snapshot.py`).** Erase-and-check over the host-marked untrusted field: if the decision is identical under every erasure of ≤ k sentences it is certified against insertion of ≤ k whole segments *at segmenter boundaries*; otherwise it escalates. Covered insertions only: merged/mid-sentence/no-space insertions are measured by a stress arm, not covered. Exact prefix-trie reuse of recurrent snapshots gives identical decisions (max |Δlogit| ≤ 1.4e-6) with 55 % (k = 1) and 60 % (k = 2) of tokens saved; calls rise 1.6×, so wall-time savings will be smaller.
- **G14 monitor (EMPIRICAL, weak, unvalidated).** The retained-norm detector for hidden-state poisoning: the originally quoted "AUROC 0.96 / 0.91" was seed 0 and is withdrawn; over 10 joint seeds RWKV-7 mean 0.57 [0.43, 0.72] (5/10 seeds at or below chance), GDN 0.86 [0.78, 0.93]. Target AUROC ≥ 0.9 is not met on either family. P itself is immune by construction.
- **G16 protected judge with a bounded evidence channel (`g16.py`).** `logit_k = b_k + a_k · E_k` with `a, b` from P only and `E_k = c·tanh(W_e h_D[k]) ∈ (−c, c)^r`. (a) veto: no untrusted text can select a host-vetoed option (STRUCTURAL); (b) isolation: `a, b` and the mask are bitwise invariant to untrusted text (STRUCTURAL); (c) **certified radius** `ρ₂ = min_j μ_ij / √(‖a_i‖² + ‖a_j‖²)` (joint) and `ρ_opt = min_j μ_ij / (‖a_i‖ + ‖a_j‖)` (per option), both tight; the reviewer's `μ/L` was shown unsound (CERTIFIED per decision); (d) independence: if `b_i − b_j > c(‖a_i‖₁ + ‖a_j‖₁)` for all allowed `j`, the decision is the same for every untrusted text and G4 holds at zero recompute (CERTIFIED); (e) otherwise G4 recomputes only E, reusing P exactly. Review fixes: a vacuous certificate on rows whose untrusted text sits outside erasable fields now escalates; non-finite E is refused. Not done: G16 as a `train/` arm, D-stream snapshot reuse, the capability cost vs the D-head arm (needs a trained run). Open non-blocking items: the `request.ssdm` declaration is caller-forgeable (host must own it), the P-only judge is nearly a per-position prior under the `provenance` policy, `u/β` indexed by row position.

## 3. Measured vs only built

**Measured, with receipts.**
- Harness parity with the official kit on DEV (gap 0.0 for three reference predictors); MDE ≈ 0.65–2.4 Index points depending on error correlation (PR #7).
- Replay fixture replays exactly; option-permutation equivariance exact on Qwen3.5-0.8B (PR #6). Stock RWKV7-0.1B and Mamba-3-187M show a strong first-sorted-option bias (issue #3), hence a debias control.
- GDN kernels: ≤ 4e-7 vs HF on real 0.8B weights (PR #9).
- Contamination guard: 14.5 % of 23,399 candidate records dropped for item-tier overlap with any of the 155,390 Index rows (20k build); 11.6 % of 169,671 (150k build); rebuilds byte-identical (PR #16, #44).
- H100 qualification phases A+B (`job-c4zkm`): 0.8B one-layer GDN conversion ΔNLL −0.0036, KL 0.017 (LEDGER); hidden cosine 0.991 **[coordinator-reported; not in LEDGER or issue #3]**. Phase C: 9B OOM at 68.9 GB.
- RWKV7-13.3B on H100 (`job-mhc3h`): prefill 3.6–4.3k tok/s, 36 GB peak, readout 0.044 rows/s under per-option recompute (`PERF_AUDIT.md`).
- controlsafe arms on tiny random models: G15 bitwise invariance, G4 snapshot savings, persistence bounds, G14 seed distribution (above).
- G4/G5 wrappers on a keyword stand-in decider: 0/400 covered insertions changed a certified decision; 4.0–5.75 % certified-and-changed on *uncovered* insertions; G5 2.2 % realised risk on held-out templates vs α = 5 %, breaks to 18.1 % under goal shift (`receipts/2026-10-06-D-g4g5-standin/`). - safety_eval smoke on stock Qwen3-0.6B: D1 steer 0.868, hijack 0.946, model at ceiling (pipeline only, PR #8).
