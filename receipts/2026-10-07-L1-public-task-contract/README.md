# Bounded public contract for L1 four-record tasks

This receipt covers the six exact read, explanation and ordered-comparison
templates emitted by the L1 four-record development generator, across legacy
and multiworld train/validation domains. All 160 generated tasks route through
`public_answer` with a scripted provider that sees only task text and the
audience-visible records. The contract binds canonical entity/field/scope
operands and preserves the user-requested comparison order. Kernel-valid
wrong-entity, wrong-field and reversed-operand proposals are refused, including
an equal-valued pair where reversing the operands cannot be detected from the
relation label alone.

This is public-boundary and fixture integration evidence only. It does not
show learned multi-record competence, exact-sum support, calibrated behavior,
neural causal mediation, or arbitrary-language coverage. All commands, cohort
hashes, source hashes and no-model/no-spend scope are recorded in
`cpu-tests.json` (historical original-head evidence).

The agent-main replay preserves the original `cpu-tests.json` verbatim, including
its original base/tested commit and historical registration-refresh entries.
Those entries do not describe the replay: no prepared-run registration files
are changed here. `agent-main-replay.json` records the current focused check,
base, exact implementation commit and source hashes. The original 375-test run
and PR #148's review are historical evidence only; no full-suite rerun is claimed
for the replay, and fresh exact-head review is required before merge.
