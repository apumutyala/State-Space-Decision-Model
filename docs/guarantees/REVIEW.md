# Adversarial review of the guarantee proofs (claude/ev-guarantee-proofs @f7170cb)

Reviewer: evidence worker, 2026-10-10. Scope: `docs/guarantees/{REORDER_INVARIANCE,CONFORMAL,INJECTION_ROBUST_CONFORMAL}.md`, `tests/guarantees/`, and the parts of `jevkit/guarantees.py` they rely on. Every issue tagged FIXED was changed on this branch, in the review commit or, for R1, the cluster commit. Line numbers refer to f7170cb.

## Summary

- **No theorem is wrong in its main claim.**
  - Split-conformal Theorem 1, LTT Theorem 2 with Bonferroni, injection Theorem A and Propositions C/D are correct as stated. Every inequality direction checks.
  - The matched `s_lo/s_lo` set is valid. `s_lo(P, y)` is a fixed function of the trusted intervals and the label. Its calibration ignores the untrusted text, so injected calibration text cannot affect it. The claimed set inclusions hold, but only under box containment on the calibration rows, which the doc had not stated (I3).
- **One bound was wrong:** the reorder float tolerance `γ_{K+2}` should be `γ_{2K}` (R2).
- **The material finding is D1** (already flagged by the author), now measured: the per-decision LTT certificate does not survive clustering (`receipts/2026-10-10-ev-guar-cluster/GUARANTEES_CLUSTER.md`).
- **Four tests could pass vacuously or circularly.** All are fixed.

## Checks that passed (tried to break, could not)

- Theorem 1 quantile: rank `⌈(n+1)(1−α)⌉`, `+∞` when the rank exceeds n, and the `≤` tie convention all match `conformal_qhat` / `prediction_set`. The upper bound `1 − α + 1/(n+1) ≥ 1` whenever `k > n`, so there is no contradiction in the `q̂ = ∞` case.
- LTT p-value direction: `p = F_{Bin(n, ε)}(e)`. Under `R > ε`, `F_ε ≥ F_R` pointwise, so `P(p ≤ t) ≤ P(F_R(e) ≤ t) ≤ t`. Valid.
- Softmax Jacobian ∞-norm `= max_i 2 p_i(1 − p_i) ≤ 1/2`, and the margin rule `> 2δ` is correct.
- `s_lo` / `s_hi` corners: `1 − softmax_y` is decreasing in `z_y` and increasing in each `z_k` (k ≠ y), so the closed forms are the exact box extremes. The test's corner search agrees.
- Proposition D (wrong bound, naive set): the inequality direction is right, and 0.559 for both is explained exactly by the adversary hitting `s_hi`.
- Training-conditional SD: `sqrt(0.9·0.1/8600) ≈ 0.0032`, as stated.
