# Free-running development runner handoff

This runner consumes only the initial empty-prefix task wording plus the supplied development world's host/catalog. It does not supply the generated gold subsequent requests to the planner. Reference programs are used only after planning by a separate scorer. Accepted semantics about the wrong fact fail task scoring; requested explanations must be present; reversed comparison operands with inverse relations are equivalent. All provider and runner failures remain in the total, with unknown work recorded as unknown.

Independent Track L review found no concrete blocker in these synthetic-domain paths. After equality was added to the generator, the test provider's strict-order assumption failed; the provider now handles equality and reversed equal comparisons. The scorer itself did not need a change for equality. The coordinator added a surface-consistency guard: a valid program paired with altered text cannot receive credit. The test provider is hand-scripted and nonlearned; passing its tests demonstrates evaluation plumbing, not learned competence.

Dependencies are the kernel in #10, renderer #11, planner/bridge #13, and development generator #15. Borrowed dependency files are not part of this worktree's implementation commit. A publication receipt must pin these exact dependencies and preserve raw observations. Do not claim standalone reproduction without supplying them.

Limits: reads, explanations of reads and two-record comparisons only. The scorer uses the same kernel semantics as the implementation; this is not independent evidence for the kernel's mathematical soundness. No natural-language parser judge, arbitrary composition, Ask scoring, strong unrestricted comparator, causal neural intervention or confidence interval is supplied here. No Index/held-out data, model weights, GPU or paid compute is used. These remain future qualification requirements, not completed goals.
